# Assembler, Linker, and Emulator Toolchain for Imaginary Architecture

This project provides an assembler, linker, and emulator for an imaginary architecture. The toolchain is designed to process assembly code, generate machine code, and simulate execution on the target architecture.

## Features

- **Assembler**: Converts assembly code to machine code.
- **Linker**: Resolves symbols and creates an executable from object files.
- **Emulator**: Simulates the execution of machine code on the target architecture.

## Requirements

- C++17 or higher
